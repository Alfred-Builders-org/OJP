---
id: P-003
title: Le confié-achat n'a pas de section dans le mode d'emploi intégré
kind: deferred
status: pending
trigger: À la prochaine reprise du mode d'emploi, ou dès qu'un utilisateur demande comment on saisit un confié-achat.
---

La page du confié-achat existe et figure dans la navigation, mais le mode d'emploi intégré ne la couvre pas : elle n'est mentionnée qu'en passant, à l'intérieur de la procédure de dépôt-vente.

Les treize procédures documentées couvrent tout le reste du produit. Constat d'inventaire.
