---
section: anti_references
---

Ce à quoi le produit ne doit pas ressembler :

- **Un tableur.** C'est ce qu'il remplace. Une grille éditable partout, sans état ni règle, reproduirait exactement le problème d'origine.
- **Une application grand public de finance.** Les grands chiffres colorés, les animations de compteur et les félicitations à chaque action sont hors de propos sur un outil qu'on ouvre huit heures par jour.
- **Un progiciel de gestion générique.** Un écran de configuration à trois cents champs pour un métier qui en a treize.
- **Une interface qui cache les règles.** Un bouton grisé sans explication vaut moins qu'un bouton actif qui dit précisément ce qui manque.
