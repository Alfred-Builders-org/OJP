Le ton est celui d'un **outil de métier tenu par un professionnel**, pas d'une application grand public.

- **Sobre.** Pas d'emphase, pas de félicitations, pas d'illustration décorative. Un écran dense qui se lit vite vaut mieux qu'un écran aéré qu'il faut parcourir.
- **Précis dans le vocabulaire.** On dit « lot », « référence », « dossier », « confié-achat », « titre », « quittance » : le vocabulaire du comptoir, pas sa traduction en langage logiciel.
- **En français correct.** Accents partout, y compris sur les majuscules et dans les libellés d'interface.
- **Explicite sur ce qui bloque.** Quand une règle refuse une action, l'écran dit laquelle et pourquoi, jamais « une erreur est survenue ».
